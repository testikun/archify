# #1139 有限实现审查

目标：Architecture 用一条关系表达同义双向关系或无向结构关联，配合随图导出的方向图例；保持旧的单向默认，避免查询和动画替关系虚构运行时数据流。

## 调用方与证据

| 范围 | 处理与验收 |
| --- | --- |
| 输入、渲染、诊断 | 仅 Architecture 接受 `direction`。`both` 两端箭头，`none` 无箭头；新关系没有传输动画标记。源端箭头也参与碰撞检查。|
| 图例 | 出现新方向时显示实际方向与实际视觉变体；保留显式隐藏、自定义标签和 all 契约。旧默认单向图的 SVG 不变。|
| Route、Reach、导出 | 双向结构查找，保留作者 ID 和几何端点；节点序列单独表示所查路径。新关系静态；方向变更或片段冲突使快照失效。|
| Focus、Intent、Lens | 独立的双向／无向计数及标识，避免把结构关联算成传输；旧单向关系保留动画。|
| Story | 源事实保留方向，新关系默认 relation 动作；显式传输动作报错。小图不补造关联箭头。|
| Delta | 缺省与显式 forward 等价；方向变化计入语义，可达性改变时也计入拓扑。|
| 其他图种 | 维持缺省 forward 的现有元数据解释；15 个已有输入、10 种图的新旧原生 SVG 完全一致。|

## 消融与测试价值

1. 移除了对旧 `viewer/guided-views.js` 的本次修改。当前模板构建不加载该文件；原有文件保持原状，新能力的实际 Story 调用方有独立测试。
2. 删除了 Route 邻接表中过度新增的可绘几何过滤。既有行为允许先按语义查路径，导出时严格检查几何。原 Route 浏览器回归捕获了这个变化；删除后旧契约与新方向检查均通过。
3. 临时删除“当前关系方向必须匹配查找时捕获的方向”的检查，运行同一新浏览器测试。关系由 both 改为 none 后仍能导出，回归断言失败；检查已恢复。证据为 [ablation-direction-snapshot.log](ablation-direction-snapshot.log)，这是有意变异实验的失败，不是最终版本失败。
4. 移除一条固定旧 Route 源码表达式的断言，用实际反向查询、稳定 ID、快照失效和分享卡导出行为覆盖它。新增测试验证用户可见结果，不冻结自动布局坐标。

没有新增图引擎、依赖或通用关系类型框架。图例复用现有放置器，遍历沿用现有 BFS，旧方向缺省保持兼容。

## 结论边界

新测试夹具是依据问题构造的功能用例，不能当作自然 Agent 失败。旧 dev 拒绝新字段证明能力边界，不证明旧版既有合同有缺陷。15 个同输入 SVG 对照证明这些旧输入的绘图兼容性，不证明新功能已在真实项目中被模型使用。正式模型 benchmark 尚未运行。

新增非英文文案通过目录与占位符检查；未声称经过独立母语审校。远端 CI、跨平台安装验证和维护者接受仍属于后续集成证据，不能由本地通过替代。
